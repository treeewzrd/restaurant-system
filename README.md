# Restaurant Order System

![Status](https://img.shields.io/badge/status-coursework-blue)

Python coursework exercise for taking menu orders and printing itemized receipts.

**Built with:** Python.

## What I built

- Implemented terminal menu selection, quantity handling, and repeat ordering.
- Calculated line-item prices and order totals, then printed an itemized receipt.

## Explore the source

- [order_system.py](order_system.py) — Ordering flow, input handling, and receipt calculations.

## Run locally

Requires Python 3. From the repository root:

```bash
python3 order_system.py
```

Choose menu items and quantities, then enter `N` to finish ordering. The program prints an itemized receipt and total. It uses terminal input and does not persist orders.

No external dependencies or automated test runner are configured.
